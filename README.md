# Strivre Solutions Wizard

Elementor widget plugin for Strivre Services' Solutions page: a multi-step configurator
(package tier → website template → domain search → solution/module selection against a
points budget → checkout) that emails staff and the customer on submission. No payment or
proposal logic lives here — the flow ends at "form submitted."

See `wp-content/plugins/strivre-solutions-wizard/` for the plugin itself. Requires Elementor.
